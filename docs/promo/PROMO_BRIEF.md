# Короткий проморолик EV Infrastructure

**Промпт для генерации (25–30 секунд, 16:9):**

> Создай сдержанный технологичный ролик о **EV Infrastructure Planning System**. Используй фирменный логотип и приложенный экран интерфейса: графитовый фон, белая типографика, один холодный бирюзовый акцент, плавное движение без неона и клише. Покажи последовательность: территория и исходные данные → варианты размещения зарядных станций и подключения → расчёт инвестиционного плана → проверка очередей и нагрузки симуляцией → сравнение сценариев. Короткие русские титры: «Где строить», «Как обеспечить энергией», «Что изменится при росте спроса», «План, который можно проверить». Финальный кадр: логотип и название проекта. Спокойный уверенный ритм, тонкая электронная музыка, без громких эффектов. **Не выдумывай реальные показатели, географию или подтверждённую эффективность:** числа из визуального макета условные; для публикации подставь фактические результаты расчёта.

`interface.html` — самостоятельный визуальный концепт интерфейса для демонстрации и видеомонтажа, `interface.png` — кадр 1920×1080. Это не реализация рабочего фронтенда; карта схематична, все показанные числа условны.
