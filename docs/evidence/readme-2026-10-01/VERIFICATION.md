# Проверка README, монохромного знака и документации

Дата: 1 октября 2026 года. Ветка `backend/algo`, checkout `E:/energy`. Проверены локальные изменения; remote CI и новый release tag не создавались.

## Изменения

- README пересобран вокруг задачи № 03, работающей программы, метода расчёта, модельного сравнения и запуска.
- Знак заменён монохромной версией; навигация, вход и metadata используют `/brand-mark.png`. Старый цветной PNG не выдаётся приложением.
- Композиция устройств содержит только снимки приложения. Видимый текст HTML вне снимков отсутствует; значения не дорисованы.
- Шесть руководств объединены в `DATA_INGESTION.md` и `CALCULATIONS.md`; отдельная презентация перенесена в корневой README. Исправлено устаревшее описание энергетического dispatch.
- Географический пример и его сборщик вынесены в `examples/regression/monaco/`, старые результаты и UI-снимки — в `evidence/`. Байты 34 не-Markdown артефактов сохранены, locks не переписаны.
- OSRM остаётся опциональным дорожным адаптером; 2ГИС отвечает за отображение. В базовом запуске нет требования OSM или конкретной территории.
- Генерируемый `tsconfig.tsbuildinfo` исключён из репозитория; локальные примеры игнорируются общим шаблоном.
