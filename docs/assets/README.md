# Изображения README

`cover.png`, `interface-showcase.png` и `calculation-flow.png` созданы из [showcase.html](showcase.html). Рамки устройств декоративны. Изображения внутри — настоящие снимки запущенного приложения: `interface/desktop.png`, `interface/mobile.png`, `interface/mobile-result.png`. На них показан сценарный Monaco-вход, не реальные спрос/резерв города.

Для обновления сначала сделайте снимки текущей сборки на 1440 × 960 и 390 × 844. Сводка телефона снята после прокрутки; необрезанный верхний экран сохранён отдельно. Зафиксируйте источник, ID расчёта, версию кода и SHA снимков в новом протоколе. Не дорисовывайте показатели и работающие слои карты.

Запустите `python scripts/preview_readme.py` из корня и откройте напечатанный loopback URL в браузере. Сервер выдаёт только `docs/assets`, два локальных шрифта и логотип; он не открывает `.env` или репозиторий целиком. Дождитесь загрузки шрифтов и экспортируйте секции: cover 1200 × 390, showcase 1200 × 884, flow 1200 × 152. После экспорта остановите preview-сервер.

Знак используется напрямую из `frontend/public/brand-logo.png`; имя и путь в приложении определены `frontend/src/lib/brand.ts`. [Источники и лицензии шрифтов](../../frontend/src/app/fonts/README.md) остаются в каталоге шрифтов. PNG-композиции не являются отдельными макетами продукта и не подтверждают достоверность модельных входов.
