# Изображения и знаки технологий

1920 × 1080, 30 кадров/с, H.264 / AAC, стерео. `energokontur-promo-poster.jpg`
— обложка ролика. Версия для README занимает менее 10 МБ.

В [основном README](../../README.md#промо-видео) видео встроено через
[вложение GitHub](https://github.com/user-attachments/assets/cb8a485d-da95-4f3a-8bee-8ee8878b90f0);
локальная копия MP4 и обложка сохранены в репозитории.

Графика города, потоков и энергобаланса — процедурные иллюстрации.
Снимки интерфейса и знак взяты из материалов проекта без изменения содержимого.
Музыка синтезирована специально для ролика, без сторонних записей и семплов.
Тексты и показатели соответствуют [отчёту проекта](../commission/REPORT.md):
сценарный эксперимент, 30 seed, CAPEX 3,70 → 5,20 млн ₽.
Условия сравнения подписаны в самом видео.

## Логотип

`frontend/public/brand-mark.png` — монохромная версия предоставленного знака: геометка, энергия и связи сети. Путь определяется в `frontend/src/lib/brand.ts`; один источник используется в навигации, входе и metadata. PNG имеет прозрачность вне тёмного основания и выдаётся напрямую.

## Стек и источники

SVG-бейджи `stack/` сохранены локально: README не требует обращения к CDN для их отображения. [sources.json](stack/sources.json) фиксирует исходные URL. Для Pyomo/HiGHS и SimPy используются знаки языка/вычислительного движка; для 2ГИС — нейтральный символ карты проекта.

- [Shields.io: логотипы и оформление бейджей](https://shields.io/docs/logos).
- [Simple Icons](https://github.com/simple-icons/simple-icons), CC0; [оговорки об использовании товарных знаков](https://github.com/simple-icons/simple-icons/blob/develop/DISCLAIMER.md). Бейджи обозначают применяемые технологии, а не партнёрство или одобрение поставщиков.
- Оформление продуктовых README изучено на [Appwrite](https://github.com/appwrite/appwrite) и [Grafana](https://github.com/grafana/grafana); тексты и изображения этих проектов не копировались.
- Локальные шрифты приложения и их лицензии: [каталог шрифтов](../../frontend/src/app/fonts/README.md).

Лицензии исходных геоданных фиксируются в манифестах конкретных наборов и [отчёте эксперимента](../commission/REPORT.md). Кодовая лицензия проекта отдельно не объявлена.
