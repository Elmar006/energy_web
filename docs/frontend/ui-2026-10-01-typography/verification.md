# Типографика и тексты · 1 октября 2026

Область изменения: визуальный слой и тексты Energy, ветка `backend/algo`. Параметры, сериализация, маршруты API и вычисления сохранены. Исходная компоновка и её протокол остаются в соседней папке `ui-2026-10-01`; эта папка относится к следующей версии интерфейса.

## Шрифты

IBM Plex Sans используется в полях, подписях, таблицах и числовых показателях. Manrope — в основных заголовках. Выбор сделан для инженерного интерфейса с кириллицей: технический основной рисунок, отдельная иерархия заголовков, табличные цифры. Варианты с одним Plex и прежним Onest рассмотрены; выбранная пара сохраняет чёрно-белую композицию без декоративного шрифта.

Оригинальные variable TTF, лицензии и SHA-256 источников хранятся в `frontend/src/app/fonts/`. `next/font/local` обслуживает их с приложения. Проверка таблиц `cmap` подтвердила русские прописные и строчные буквы, включая Ё/ё, латиницу, цифры и символы ₽, ·, –, %. Браузерный тест проверяет фактическую загрузку обеих семей, использование основной семьи полями и отсутствие внешних запросов шрифтов.

## Проверка

ESLint, TypeScript и производственная сборка прошли. Браузерный набор включает 26 тестов: девять рабочих URL на шести ширинах, семь представлений результата, формы, клавиатуру, основные контрастные пары, загрузку шрифтов и сквозной путь через Go API / worker / Python с экспортом. Точный итог и время — в [логе](playwright.log); образ, базовый commit, хеши источников и снимков — в [протоколе](verification.json). Рабочая копия содержит незакоммиченные изменения; один HEAD не идентифицирует поставку.
