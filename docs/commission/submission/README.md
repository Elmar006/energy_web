# Энергоконтур — материалы для комиссии

Решение задачи № 03 «Зарядка электромобилей в мегаполисах» для ООО «Росатом Сеть зарядных станций».

| Файл | Назначение |
|---|---|
| [Презентация PowerPoint](Энергоконтур_решение_задачи.pptx) | 12 слайдов с редактируемыми текстами, схемами, таблицами и диаграммой |
| [Презентация PDF](Энергоконтур_решение_задачи.pdf) | Версия для просмотра с сохранённым оформлением |
| [Отчёт для комиссии](Энергоконтур_отчёт_для_комиссии.pdf) | 6 страниц с последовательным объяснением способа решения |

Материал раскрывает, как потребность транспорта превращается в план размещения, оснащения, энергоснабжения и инвестиций; как проверяется работа отдельных станций и соседней сети; какие решения принимает заказчик. Техническое устройство приведено в конце. Пример показывает рост обслуживания при дополнительных вложениях; его исходные предположения обозначены.

Снимки иллюстрируют рабочий интерфейс и относятся к отдельному сохранённому расчёту. Численное сравнение планов приведено на слайдах 8–9 и страницах 4–5 отчёта.

В PowerPoint используются Manrope и IBM Plex Sans. Исходные шрифты и лицензии находятся в `fonts/`. В PDF шрифты встроены. Пояснения к слайдам сохранены в заметках докладчика.

Перед отправкой добавьте сведения команды и образовательной организации, если они требуются формой подачи. Обеспечьте комиссии доступ к [репозиторию проекта](https://github.com/Elmar006/energy_web).

Подробные расчётные доказательства доступны отдельно: [методика и результаты сравнения](../REPORT.md), [сопоставление с конкурсной задачей](../TASK_FIT_AUDIT.md). В презентацию не включены внутренние протоколы разработки.
