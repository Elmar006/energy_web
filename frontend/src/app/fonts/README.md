# Локальные шрифты

IBM Plex Sans — интерфейс, таблицы и числовые показатели. Manrope — заголовки. Подключение: `src/app/layout.tsx` через `next/font/local`; CSS-токены `--font` и `--font-heading`.

Оригинальные variable TTF из репозитория Google Fonts сохранены без изменения. Кириллица, латиница, цифры и символы `₽ · – %` присутствуют в обоих файлах. Применяемые веса: 400, 500, 600; поддерживаемые диапазоны Plex 100–700, Manrope 200–800. Загрузка шрифтов с внешних доменов не используется.

Источники с закреплёнными ревизиями, размером и SHA-256: [sources.json](sources.json). Условия распространения включены отдельно: [IBM Plex Sans](ibmplexsans-OFL.txt), [Manrope](manrope-OFL.txt). Эти файлы должны поставляться вместе со шрифтами.
